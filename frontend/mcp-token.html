HOW IT WORKS

当前登录态直接签发

  • 页面从浏览器登录态获取当前用户名。
  • 点击按钮后，服务端按当前账号策略签发 MCP Token。
  • 密码不会出现在页面、请求参数、配置或日志中。
  • Token 只应粘贴到可信的智能体配置中。
